process_raw creates a pcd object and optionally saves it as ply. we are using this function in PiLiDAR.py and process_3D.py , but lidar_geometry.md describes a calibration issue that we currently have in this project. an intermediate solution is to use split_fans.py to break create two ply files, one only assembled from the left half of each 2D lidar plane and the other from the right half, resulting in two point clouds that are consistent within themselves but have a fix position and rotation offset to each other. we can use registration_test.py to measure the offset using ICP once, then store the resulting calibration data in config.yml so we don't need to run ICP for the left/right half pairs the next time. please create a helper function in lib/ that contains the split_fans functionality and the RANSAC/ICP registration workflow, then integrate the split_fans function and with the stored offset into the process_raw function.
